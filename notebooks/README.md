# Notebooks

Esta carpeta empieza vacía a propósito. Cuando le pidas al agente que haga
el análisis con los datos de un año determinado, va a generar acá un
notebook nuevo (por ejemplo `Analisis_ECH_2024.ipynb`), siguiendo la
estructura estándar documentada en [`docs/METODOLOGIA.md`](../docs/METODOLOGIA.md).

Los notebooks generados no se suben al repositorio (ver `.gitignore`) salvo
que decidas publicarlos vos mismo.
