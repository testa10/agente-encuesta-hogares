# Notebooks

Esta carpeta empieza vacía a propósito. Cuando le pidas al agente que haga
el análisis con los datos de un año determinado, va a generar acá un
notebook nuevo (por ejemplo `Analisis_ECH_2024.ipynb`), siguiendo la misma
estructura que el análisis original de 2019
(ver [Narrativa_de_Datos](https://github.com/testa10/narrativa-datos) y su
[informe publicado](https://testa10.github.io/narrativa-datos-informe.html)
como referencia de lo que se espera obtener).

Los notebooks generados no se suben al repositorio (ver `.gitignore`) salvo
que decidas publicarlos vos mismo.
